# Valorización SIS — edición UX/UI

Se conserva la lógica de valorización, los filtros, las pestañas y las fuentes de datos. El rediseño ordena la jerarquía visual, amplía los gráficos, mejora contraste y legibilidad, adapta la navegación a móvil y permite recorrer las pestañas con teclado.

## Abrir el dashboard

1. Extrae esta carpeta completa.
2. Abre una terminal dentro de la carpeta y ejecuta `python -m http.server 8765`.
3. Visita `http://localhost:8765` en tu navegador.

El servidor local permite cargar los archivos JSON que están en `data/`. También puedes publicar toda la carpeta en un hosting estático. No abras `index.html` con doble clic, porque el navegador puede bloquear la lectura local de los datos.

Consulta `README.md` para conocer el flujo de actualización y las definiciones del análisis.
